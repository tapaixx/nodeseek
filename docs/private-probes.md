# 非公开极简探针

1. 打开探针的添加或编辑页，类型选择「极简探针」，填写 HTTPS 面板地址。
2. 点击「登录账户」，在独立页面完成面板配置的 GitHub 登录或应急密码登录。
3. 点击「完成登录」。App 会确认会话有效，再保存登录状态并重新测试连接。
4. 连接成功后保存面板，即可在原生列表查看登录后可见的服务器与历史指标。

已有面板可点击「重新登录账户」更换或更新登录状态；会话过期时需要重新登录。「退出面板账户」清除本机保存的会话与快照。删除面板也会移除对应会话。

会话按探针和 HTTPS 地址分别保存在本机 Keychain，不保存密码，也不保存 GitHub Cookie。账号与 NodeSeek 的登录状态相互独立；切换面板地址不会把旧会话发到新地址。

私有面板的小组件使用 App 更新的共享快照，不持有面板会话；需要更新私有数据时打开 App 刷新。公开面板的小组件继续独立联网更新。

接口依据[极简探针官方认证实现](https://github.com/monitor-probe/monitor/blob/main/src/auth.rs)及[路由与会话查询](https://github.com/monitor-probe/monitor/blob/main/src/api.rs)：后台入口 `/admin/nodes`，会话 Cookie 为 `monitor_session`，`/api/me` 的 `authed` 用于确认登录。

验证覆盖会话的域名、过期与 HTTPS 限制，私有列表及历史请求携带会话，其他面板不复用会话，退出后拒绝读取私有缓存，以及私有小组件的缓存行为。模拟器测试使用虚构会话，仍需用自己的面板完成实际登录验收。
