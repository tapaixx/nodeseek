# 原生交易系统功能补齐

以 docs/native-trade-feature-audit.md 和 2026-11-23 登录后只读核对为基线。保留现有交易 API 签名、Cookie 隔离和写入不自动重试约束。不使用真实交易执行测试。

## 顺序与验收

1. 统一原生导航：大厅／聊天／我的；所有功能通过明确入口发现。
2. 大厅：中介资料、托管列表／详情／发布与权限内操作、品牌统计、交易查询／风险查询、公开记录、等待接单、计算器、反馈。
3. 聊天：群聊／私聊、服务端筛选、无指定中介建群、申请记录与处理、消息隐私／图片／引用／编辑／删除／表情／置顶／历史、快捷消息、交易管理与评价。
4. 我的：概览、资料、Telegram、快捷消息、API Key、积分／明细／红包／兑换／订单／提现确认、使用帮助。
5. 交易详情补费用结算、风险、交货方式／品牌／外币编辑、解锁／三方申请／退出／取消／旁观者。
6. 验证：模型与接口契约、写入重复保护、服务端权限、敏感可见范围、暗黑与动态字号、输入与键盘；Mac 使用项目 Make 目标。发布沿用 OMacBook runner。

每项分别记录已实现与验证边界。中介／管理专属面板由服务器按角色加密分发；当前账号无此角色，不能从普通账号虚构端点或宣称完成。可接入已有证据的中介等待接单和托管操作，其余须有对应角色的正式接口证据。
