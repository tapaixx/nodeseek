# 探针三网与线路质量

服务器详情新增「三网与线路」，显示面板配置的线路名称、延迟、丢包率与采样趋势。点击不同线路切换图表；1H / 6H / 24H 同时切换资源和线路历史。

- Komari：列表使用已有状态中的Ping摘要，不增加逐节点请求；详情读取独立Ping历史。
- 极简探针：详情读取 `series=ping`，复用面板登录状态，支持非公开面板。
- CF-Server-Monitor：列表使用已有三网/BGP/自定义线路指标，详情读取资源历史中的线路字段，并读取面板自定义名称。

方向是「服务器 → 面板监测目标」，不是手机到服务器测速。Komari、极简探针的任务名由管理员设置，不会按任务编号猜测运营商。CFSM的CT/CU/CM是面板字段，详情优先显示自定义名称。

逾时显示「超时」，延迟图断线；未采样显示「尚未采样」，未提供指标显示「—」。不把未配置的false或null当作0ms/0%丢包。

极简探针显示时间桶的中位延迟，整窗丢包直接使用面板统计，不平均桶丢包率。Komari列表标示最近成功延迟，详情保留服务端整窗统计。CFSM历史丢包是采样点/桶统计，不当作整窗平均。详情会标示对应统计范围。

线路历史按需读取并缓存一分钟；不随列表节点数发起额外Ping历史请求。退出私有面板后无法读取其历史缓存。读取失败显示错误，不覆盖成健康的零丢包数据。

接口与字段依据见[三种面板的官方源码研究](probe-network-research.md)。自动验证使用合成数据，真实线路需由面板管理员先配置监测任务。
