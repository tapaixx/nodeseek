# 原生交易功能覆盖与验证

以登录后核对文档 native-trade-feature-audit.md 为基线。

| 模块 | 当前接入 | 验证范围 |
| --- | --- | --- |
| 主结构 | 大厅／聊天／我的，原生导航 | 模拟器与导航回归 |
| 大厅 | 中介资料、托管列表详情、品牌统计／趋势表、查询风险、公开记录、计算器、反馈 | 普通账号只读响应 + 模拟页面 |
| 托管写入 | 发布、接取、拒绝、改指定、撤下、建群、主动查看货物 | 契约和权限模拟，未真实提交 |
| 创建与申请 | 可空标题、无指定／指定／通知全部中介、私聊和建群请求、同意／拒绝／撤回 | 模拟提交与重复保护 |
| 消息 | 多行、图片、私密接收人、回复引用、表情、编辑删除、置顶、编辑记录及可见性 | 模型、传输和模拟布局；非空私人会话未真实验证 |
| 交易管理 | 费用结算、风险、条款编辑、三方提案、角色／退出／取消／旁观、评价、允许撤销的进度 | 模拟状态和权限，未真实转账放货 |
| 我的 | 概览、资料、Telegram、快捷消息、Key、积分／兑换／红包／订单／提现 | 空态只读接口 + 模拟写入，未真实支付或资产操作 |
| 实时 | 官方 WebSocket，后台与不可见时停止，详情轮询恢复 | 编译与生命周期路径；网络断线恢复需持续实机观察 |
| 中介角色公共入口 | 等待接单、托管操作、权限内公开审批 | 有官方脚本契约，无中介账号实测 |
| 独立中介工作台 | 未接入 | 服务端加密分发，缺少有权角色的正式接口证据 |
| 管理员工作台 | 未接入 | 同上 |

“接入”表示原生界面和请求已实现，不表示真实业务写入已验证。不得将只读页面、构建成功或模拟测试表述为真实资金／货物流程验证通过。
